# Project Development Process

## Process Model

I am using Scrum as the Agile process model.

## Why Scrum

I selected Scrum because of my project being about a smart study planner than it will be changed to fit the needs of students. This lead to picking Scrum as my choice between the two.

Our project has everchanging uses, which makes short development
cycles useful because as education constantly changes the constant change for the project will help.

## Sprint Structure

Our team will use 6 sprints.

Each sprint will have:
- Sprint planning
- Development
- Review
- Retrospective

## Backlog

Our initial backlog contains:
1. As a student, I want to create an account so that I can save my schedule.
2. As a student, I want to log in so that I can access my schedule.
3. As a student, I want to add courses so that I can build my schedule.
4. As a student, I want to remove courses so that I can change my schedule.
5. As a student, I want to view my schedule so that I know when my classes occur.
6. As a student, I want to receive validation when courses conflict so that I don't create an impossible schedule.
